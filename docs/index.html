      The PubMed column is the total returned by PubMed for the species clause combined with the topic clause of the row. The OpenAlex column counts only journal articles that are not already in that set: OpenAlex articles that carry a PubMed identifier are treated as the same document and are not added, and items that do not concern the species or that duplicate another version of the same work are excluded. Each remaining article is assigned to a topic if its title matches the topic keywords (English, Portuguese and Spanish) or if the abstract held by OpenAlex contains the specific terms of the corresponding PubMed clause. The abstract search was run on the OpenAlex server, was restricted to records that name the species, and uses the specific phrases of each clause (for example “protected area” or “conservation status”) and not generic words such as “conservation” or “management”, which would match almost every record. This reduces, but does not remove, the asymmetry between the sources: OpenAlex holds no abstract for some records, which remain matched on the title alone, and the keyword rules are a heuristic and not a manual classification, so some broad clauses (for example monitoring, threat mapping and policy) may include studies that are only tangentially related. Three rare phrases (management unit, growth layer and population decline) could not be queried individually and were not applied at abstract level. The SciSpace column counts records returned by the SciSpace search shown above (up to one hundred records published since 2015) that match neither PubMed nor OpenAlex by normalised title: of the one hundred records, 63 were already in OpenAlex, 11 in PubMed, 5 were duplicate versions within SciSpace and 12 were set aside because they concern other species, are occurrence datasets or are taxonomic reference entries; the remaining 9 were added and assigned to topics by reading the title and abstract excerpt. The integrated count therefore counts each document once. A record may match several topics, so counts overlap and must not be added. Neither index covers all regional journals, theses and technical reports, so every count is a lower bound, and a low count indicates a gap in indexed evidence and not an absence of knowledge. Topic clauses are a heuristic proposed for review by the CMP coordinators; several are deliberately broad and are flagged in the notes. Actions that concern governance or capacity building (MON#003, PACB#003 and PACB#004) are not measured by a literature count, and the counts for PACB#001 and PACB#002 are indicative only.

      Updating the evidence base

      The dashboard reads its data from attached files and live queries; the page itself has no network access. Five routes keep it current.

      1. Revised CMP or SALVE documents. Where a document is revised, ask Claude to re-extract the affected tables (actions, threats, management units, indicators); the corresponding data files are then replaced and the page redraws without further change.
      2. Direct replacement of a data file. Editors may open Sources, select a dataset and replace its attached file with a corrected version that keeps the same column headings.
      3. PubMed and SciSpace (live). The recent-records tables query PubMed and SciSpace through their connectors whenever the dashboard is opened or refreshed. The annual PubMed series is a dated snapshot and can be regenerated on request; the same applies to the PubMed counts per action and per PAN objective and to the list of CMS and IWC instruments, which can be rerun or extended on request.
      4. OpenAlex (open API). The OpenAlex series, the most-cited works and the OpenAlex records added to the counts per action and per PAN objective are dated snapshots. A new snapshot can be requested at any time; it replaces the attached files and is deduplicated against PubMed by identifier, so that no document is counted twice. The same snapshot re-runs the abstract-level topic search on the OpenAlex server and compares the current SciSpace results with the integrated set by normalised title, so that records found only in SciSpace are added once.
      5. Scopus and Web of Science. Both require institutional licences and keys, so they cannot be queried from this page. Export the search results (CSV or tab-delimited) and replace the most-cited-works file in Sources; common headings (title, authors, source title, publication year, cited by or times cited, DOI) are mapped automatically.
